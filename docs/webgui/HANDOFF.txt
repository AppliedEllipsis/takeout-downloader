## 1. Mission
We are turning the existing Google Takeout downloader into a web-hosted system:
a real Chrome browser runs ON the server inside a webtop (KasmVNC) container,
logged into Google once with a persistent profile. A custom extension captures
the Takeout "all exports" payload and POSTs it to a local FastAPI "manager"
service, which drives the existing `takeout_dl.py` engine to download every part
using server storage/bandwidth. Because browser and downloader share one server
IP, the IP-bound Takeout cookie is always valid (no SOCKS tunnel). The manager
shows live progress, notifies over Telegram, exposes a control API for the Pi
agent, and can replay a saved workflow with no LLM. Full design lives in
`docs/webgui/`. THIS handoff covers Phase 1 only: the single additive engine
refactor that everything else depends on.
