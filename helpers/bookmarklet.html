📦 Takeout Downloader Bookmarklet

Drag the link below to your bookmarks bar. When you're on a Google Takeout page and click a download, the bookmarklet will capture the URL and cookie and send them to your downloader server.

📥 Send to Takeout Downloader

Setup Instructions

1. Start your downloader server
python google_takeout_web.py or via Docker
2. Drag the bookmarklet above to your browser's bookmarks bar
3. Go to takeout.google.com, click your download link
4. Click the bookmarklet — it will prompt for server URL, detect the download link, and send the request

Bookmarklet Source (for review)



    

        Note: The bookmarklet uses document.cookie which may not include all authentication cookies (especially httpOnly ones). For full cookie capture, use the Tampermonkey userscript instead, which intercepts the actual network requests including all headers.
    


    
Alternative: Tampermonkey Userscript

    
For more reliable cookie capture, install the takeout-extractor.user.js userscript in Tampermonkey or Greasemonkey. It automatically intercepts network requests and captures the full cookie header.
