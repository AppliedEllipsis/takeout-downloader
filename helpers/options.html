⚙️ Takeout Helper Settings

Security notes:
• Server URL is validated: only http:// or https:// are accepted.
• For non-localhost URLs you'll be asked to confirm once per session before each send.
• Your captured Google session cookie and auth password are stored in chrome.storage.local (plaintext, sandboxed to this extension).
• autoSend=true fires on every matching capture — keep it off until you've confirmed the server URL is correct.
